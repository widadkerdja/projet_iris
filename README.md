# Classification des Fleurs d'Iris

Ce projet a pour objectif de construire un modèle simple de machine learning 
permettant de classifier les fleurs d'Iris en trois espèces :
- Iris setosa
- Iris versicolor
- Iris virginica

Outils et bibliothèques utilisées :
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn (KNN)

Structure du projet :
- donnees/ : jeux de données
- notebooks/ : notebook principal Iris_Classification.ipynb
- scripts/ : scripts Python éventuels
- resultats/ : résultats et fichiers générés

Instructions :
1. Lancer Jupyter Notebook avec la commande :
   jupyter notebook
2. Ouvrir le fichier :
   notebooks/Iris_Classification.ipynb
3. Exécuter les cellules étape par étape.
